Rapid Parcels

This example demonstrates one Arazzo workflow using three different OpenAPI specs: to ship a parcel, it gets a quote from rates.yaml, a shipment and its label fromshipments.yaml, and a tracking subscription from tracking.yaml. Each step's outputs feed the next, from one OpenAPI spec to another.

On the right, each OpenAPI spec has its own <rapi-doc-mini>, showing only the operations the workflow calls in it. Click a step to open its operation there, or run the workflow: RapiDoc's in-browser mock answers every request from the OpenAPI specs' examples and schemas, so nothing leaves the page.
