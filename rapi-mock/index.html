rapidoc mock • @rapidoc/mock

RapiMock

Your OpenAPI spec as a server that remembers. RapiMock serves every operation of your spec, validates requests, checks tokens, and keeps what you create, so a POST shows up in the next GET. No code to write.

QuickstartCheck your specDocumentation
One Command

A Mock That Keeps What You Send

Point rapidoc mock at a spec. Each API is served under its own path on port 4010; with--stateful, records you create are there when you read or list them, until you reset.

Your frontend, your tests, <rapi-doc>'s Try and an MCP server can all call it, the way they will call the real API.

terminal
npm install -D @rapidoc/cli @rapidoc/mock
npx rapidoc mock openapi.yaml --stateful

curl -X POST localhost:4010/openapi/pets \
  -H "Content-Type: application/json" -d '{"name":"Biscuit"}'
curl localhost:4010/openapi/pets        # Biscuit is in the list
What You Get

More Than Canned Examples

State, worked out from the spec

It reads resources, keys and links off your paths and schemas, starts with generated records, and keeps what you create, change and delete.

Read more

A UI to look inside

See the records, what the mock does for every operation, and how sure it is. Reset the data or reseed it from the page.

Read more

Tests in any language

Reset, read and load the data over HTTP, with a session per test so parallel tests never see each other's changes.

Read more

Requests and tokens checked

A bad request gets a 400 with the problems listed. OAuth tokens are verified against your issuer, scopes included.

Read more

You can correct it

Where a spec doesn't show its data model, state it in a few lines of mock.config.yaml. Stale entries are reported, never ignored.

Read more

Check your spec first

rapidoc lint --stateful reports what the mock had to assume, at its place in the spec, before you run anything.

Two Mocks

In the Page or as a Server

<rapi-doc> also has a mock inside the browser, for docs and demos. They are built for different work.

In-browser mockRapiMock
RunsInside the pageAs an HTTP server
Who can call itThe page itself: Try, <rapi-flow>Anything: curl, your frontend, tests
Request validationNoYes
Token and scope checksNoYes
Remembers what you createNoYes, with --stateful

RapiMock reads the data model off the spec. It does that well for APIs with ids in the path and keys at the top of a record, and needs a few lines of config for other styles:see which, with examples.
