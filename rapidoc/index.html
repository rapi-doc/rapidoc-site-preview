Framework Agnostic

Native W3C Web Component Standard

Free of proprietary wrapper lock-in, complicated build steps, or framework runtime baggage. Drop a single <rapi-doc> custom element into React, Vue, Angular, Next.js, Nuxt, Astro, or plain vanilla HTML. Change attributes with JavaScript and it responds instantly.

Real DX

Built-in Console with Negative Testing

Execute API calls directly in the docs. Unlike rigid renderers that block invalid inputs, RapiDoc lets you test negative edge cases, corrupt payloads, and custom headers.

Zero Setup

In-Browser Mock Server

Frontend teams can prototype before the backend is built. Seamlessly intercepts in-page fetch() calls and generates realistic mock responses from OpenAPI examples or schemas with multi-status and latency simulation.

Explore Mock Server
Agent Ready

Curated MCP Server Generator

Convert OpenAPI specs into a Model Context Protocol manifest with JSON Schema tools, MCP safety annotations and a runnable TypeScript project. Skips internal and deprecated endpoints, strips transport headers and keeps a live budget of prompt context overhead.

Microservices & Edge

Embedded in Micro-Servers & Containers

With its tiny bundle size and zero server-side rendering dependencies, RapiDoc is ideal for embedding into lightweight Docker containers, Go / Rust / Java backends, and IoT edge devices.

Ergonomics

Get Up & Running

Zero Config, Instant Integration

Save this as a file and open it in a browser. The same element works in any framework.

HTML
index.html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <script type="module" src="https://unpkg.com/rapidoc/dist/rapidoc-min.js"></script>
    <style>
      body { margin: 0; }
      rapi-doc { height: 100vh; }
    </style>
  </head>
  <body>
    <rapi-doc spec-url="https://rapidocui.com/specs/petstore.yaml"></rapi-doc>
  </body>
</html>

One script tag and one element. Nothing to install or build. Quickstart · React, Vue, Angular, Svelte · Without a CDN
